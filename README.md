# Slyrix Viewer Landing

Лендинг для сбора предложений от зрителей канала SLYRIX. Две формы: идеи для видео и команды для nightbot'а.

## Стек

- **Чистый HTML/CSS/JS** — без фреймворков
- Дизайн в стиле основного сайта модераторов (тёмная тема, Space Mono)

## Структура

```
frontend/
├── index.html      — лендинг с сайдбаром и тремя вкладками
├── css/style.css   — стили (тёмная тема, чипсы-радио, анимации)
└── js/
    ├── config.js   — URL бэкенда
    └── app.js      — навигация по вкладкам + отправка форм
```

## Как работает

1. Пользователь заполняет форму на одной из вкладок
2. Данные отправляются POST-запросом на бэкенд `slyrixwiki`
3. Бэкенд сохраняет запись в SQLite (таблицы `nightbot_suggestions` / `video_ideas`)
4. Модераторы видят новые предложки в админ-панели

## Настройка

В `js/config.js` заменить `API_BASE` на нужный URL бэкенда.

## Запуск

Просто открыть `frontend/index.html` в браузере. Никакого сервера не требуется — статика.
